# Libft - my first c library

## คำอธิบาย (Description)
โปรเจกต์นี้คือการเขียนไลบรารีด้วยภาษา C ซึ่งรวบรวมฟังก์ชันอเนกประสงค์มากมายที่จะเป็นเครื่องมือสำคัญสำหรับการเขียนโปรแกรมในอนาคต เป้าหมายคือการทำความเข้าใจว่าฟังก์ชันมาตรฐานของ C ทำงานอย่างไรโดยการเขียนมันขึ้นมาใหม่ตั้งแต่ต้น

### รายละเอียดของไลบรารี
ไลบรารี `libft.a` ประกอบด้วยฟังก์ชัน 3 กลุ่มหลัก:
1. **ฟังก์ชัน Libc (ส่วนที่ 1):** การเขียนฟังก์ชันมาตรฐานจากไลบรารี C ขึ้นมาใหม่ เช่น `ft_strlen`, `ft_memset`, `ft_atoi`, `ft_isalpha` เป็นต้น
2. **ฟังก์ชันเพิ่มเติม (ส่วนที่ 2):** ฟังก์ชันที่มีประโยชน์สำหรับการจัดการข้อความ (String) และการจัดการหน่วยความจำที่ไม่มีในไลบรารีมาตรฐาน เช่น `ft_split`, `ft_itoa`, `ft_strjoin`
3. **Linked List (โบนัส - ส่วนที่ 3):** ฟังก์ชันสำหรับจัดการโครงสร้างข้อมูลแบบ Linked List โดยใช้โครงสร้าง `t_list` แบบกำหนดเอง (เช่น `ft_lstnew`, `ft_lstadd_front`)

## คำแนะนำการใช้งาน (Instructions)

### สิ่งที่ต้องมี
- คอมไพเลอร์ภาษา C (เช่น `cc` หรือ `gcc`)
- คำสั่ง `make`

### การคอมไพล์ (Compilation)
ในการสร้างไลบรารี ให้เข้าไปที่โฟลเดอร์หลักของโปรเจกต์ (root) และใช้คำสั่ง:
```bash
make
คำสั่งนี้จะสร้างไฟล์ไลบรารี libft.a ขึ้นมา

คำสั่ง Makefile ที่สามารถใช้ได้:

make หรือ make all: คอมไพล์ฟังก์ชันบังคับทั้งหมด

make bonus: คอมไพล์ไลบรารีรวมถึงฟังก์ชัน Linked List ในส่วนโบนัส

make clean: ลบไฟล์ object (.o) ที่เกิดจากการคอมไพล์ทั้งหมด

make fclean: ลบไฟล์ object (.o) และไฟล์ libft.a

make re: ลบไฟล์ทั้งหมดและทำการคอมไพล์ไลบรารีใหม่ตั้งแต่ต้น

การนำไปใช้ (Usage)
เพิ่มไฟล์ Header ลงในโค้ดภาษา C ของคุณ:

C
#include "libft.h"
จากนั้น ตอนคอมไพล์โปรแกรมของคุณ ให้ลิงก์ไลบรารีเข้าไปด้วยคำสั่ง:

Bash
cc -Wall -Wextra -Werror your_program.c -L. -lft -o program_name
